# TripCost v3 - 상세 분리형 가성비 여행 플래너

## v3 업데이트 (2026-10-13)
사용자 피드백 반영: 숙박, 교통, 식사, 관광 완전 분리

### 주요 기능
- **검색형 목적지**: 27개 도시 한글/영문/공항코드 검색 (후쿠오카 FUK 기본)
- **기간 선택**: 시작일/종료일 모두 지정 가능 + 2박3일/3박4일/4박5일 퀵 버튼
- **숙박 비교**: 4개 호텔 실데이터 비교표 (가격/평점/거리/장단점/조식/취소)
  - EN HOTEL 78,000원, Forza 92,000원, WeBase 65,000원, Active 58,000원
- **교통**: 공항-시내 비교표, 패스 비교 (지하철 1일권 640엔), 일별 비용
- **식사**: 아침/점심/저녁 분리, 8개 실명 식당, 가격, 혼밥 여부, 4일 총액
- **관광**: 6개 명소 입장료/소요시간/운영시간/추천시간대 + 일자별 동선
- **예산**: 항공 247,500원 + 선택 숙박 + 교통 + 식사 + 관광 합산
